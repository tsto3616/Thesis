# **Kraken2 branch:**

## **This branch represents a discussion point on the Kraken2 software and decontamination in general for hookworms and other parasites. This branch is a mix of Galaxy Australia and R coding.**

### **The data:**

The data was generated by filtering the genome of *Uncinaria stenocephala* to a minimum of 1000 nucleotide long scaffolds and compared to the published genomes for the hookworms *Ancylostoma caninum, Ancylostoma ceylanicum, Ancylostoma duodenale* and *Necator americanus*. The published genomes were downloaded from WormBase Parasite for unmasked genomes originating from the BioProjects: PRJNA20441, PRJNA231479, PRJNA72581 and PRJNA1007425 respectively. Each genome was processed through Kraken2 in Galaxy Australia using the MiniKraken2 v2 reference library. All settings were the default for Galaxy Australia's Kraken2 version 2.1.3. The Kraken2 results for each genome were processed together through Recentrifuge v1.16.1. The only change in settings was altering the input file to be the Kraken database.

### **The coding:**

The coding used the csv file created for this purpose to be used for a chord plot in R. All coding in this section is using R. First load the necessary libraries for R:

```         
library(tidyr)
library(dplyr)
library(circlize)
```

Now load the dataframe from the csv and then go and manipulate the format. The csv file can be found in the branch under the name "recentrifuge-kraken2-hookworms.csv":

```         
kraken_csv<- read.csv("recentrifuge-kraken2-hookworms.csv")

classifiers<-  c("Human", "Bacteria", "Archaea", "Viruses", "Unclassified")

kraken_long <- kraken_csv %>%
  pivot_longer(cols = classifiers,
               names_to = "Classification",
               values_to = "Proportion")

# Prepare matrix for chord diagram
mat <- xtabs(Proportion ~ Genome + Classification, data = kraken_long)

# Plot chord diagram
chordDiagram(mat, transparency = 0.3)
```
